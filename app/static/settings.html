연결 설정

토스증권

현재 로그인 계정의 연결 정보만 저장하고 조회합니다.

계좌·보유종목 조회와 실시간 시세를 연결합니다. 실제 주문은 전송하지 않습니다.

설정을 확인하고 있습니다.

확인 서비스로 접속한 현재 IPv4입니다. 고정 IP가 아니며 토스 요청에 사용되는 IP와 다를 수 있습니다. 토스 허용 IP에 등록한 뒤 연결 테스트를 실행하세요.

연결 준비 방법

토스증권 WTS의 설정 → Open API에서 발급한 Client ID·Secret을 입력하세요. 토스 허용 IP에는 휴대폰 IP가 아닌 Render 서버의 발신 IP를 등록해야 합니다. 위 서버 발신 IP 확인 버튼으로 현재 IP를 확인할 수 있습니다. Render의 Outbound에 표시된 /24는 IP 범위이며, /24를 지운 시작 주소가 실제 발신 IP라는 뜻은 아닙니다.

암호화 키 미설정 안내가 나오면 Render 환경변수 INVESTPILOT_SETTINGS_KEY에 Fernet 키를 설정하고 재배포하세요. Python에서 python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"로 생성합니다. 키는 계속 같은 값을 유지하세요.

로그인 계정 관리

관리자만 새 계정을 추가할 수 있습니다. 새 계정의 토스 연결 정보는 별도로 설정합니다.
