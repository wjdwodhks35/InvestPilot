PC에서 실행하는 방법

PC에서 Ollama를 켜고 InvestPilot 폴더의 터미널에 아래 명령을 입력하세요. 내로그인계정을 실제 플랫폼 로그인 이름으로 바꾸고, 요청하면 플랫폼 비밀번호를 입력합니다.

python -m scripts.ollama_remote_paper --username 내로그인계정

한 번 실행하면 최신 시세 조회 → AI 판단 → 가상 체결 → 아래 결과 표시 순서로 진행합니다. 새 판단은 명령을 다시 실행합니다. 이 페이지는 10초마다 결과를 확인합니다.

웹사이트만 열어 두면 PC 모델이 자동으로 실행되지는 않습니다. PC가 꺼져 있으면 판단도 멈춥니다. 실행 중 세부 단계는 PC 터미널에서 확인합니다.

처음 설치할 때만: ollama pull qwen3:4b
