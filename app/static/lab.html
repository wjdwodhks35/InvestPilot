모델 실험실 Experimental

과거 가격·뉴스로 확률 모델을 연구하는 별도 테스트 공간

현재 단계: 데이터 검사

학습 모델과 검증된 상승·하락 확률은 아직 없습니다. 이 공간의 데이터와 결과는 매매 엔진에 전달되지 않습니다.

과거 데이터 검사

CSV를 선택하거나 붙여넣으세요. 데이터는 검사 요청에만 사용하며 저장하지 않습니다.

필수 열: timestamp, symbol, close, volume
선택 열: news_title, news_published_at
시간대 포함 시각을 사용하세요. 해당 행의 timestamp는 판단 가능한 시점입니다.


학습 기능 개발 순서
  1. 당시 뉴스·가격 데이터 확보 및 시점 검증
  2. 가격 기준 모델과 가격+뉴스 모델 비교
  3. 시간순 검증 및 예측 기간에 따른 경계 간격 적용
  4. 확률 보정·평가 지표·실험별 결과 비교
