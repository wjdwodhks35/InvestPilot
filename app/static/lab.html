Ollama AI 가상투자 테스트

Render의 127.0.0.1은 사용자 PC가 아닙니다. 무료 PC 모델은 아래 실행기로 연결합니다. PC가 꺼져 있으면 추론과 학습은 실행되지 않습니다.

PC Ollama 연결 및 데이터 준비

PC에서 Ollama를 실행하고 ollama pull qwen3:4b로 모델을 설치하세요. 저장소에서 의존성 설치 후 아래를 실행하면 최신 삼성전자 토스 시세로 AI가 1회 모의 판단합니다. 모델 가중치를 학습하는 작업과 다릅니다.

python -m scripts.ollama_remote_paper --username 내로그인계정

플랫폼 비밀번호는 실행 시 입력합니다. 토스 키는 PC 실행기에 전달하지 않습니다. 먼저 아래 정지 해제 버튼을 누르세요.

python -m scripts.ollama_remote_paper --username 내로그인계정 --export

내 시세 관측·AI 판단 기록을 data/worker에 내보냅니다. Google Drive 저장은 기존 scripts.drive_storage를 사용합니다. 체결 관측은 일봉이 아니므로 기존 일봉 모델 학습에 그대로 쓰면 안 됩니다.
