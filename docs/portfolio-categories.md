# 내 카테고리 자산·배당 가정·환율 조회 기록

기존 실제 계좌 대시보드를 확장한다. 모의 잔고와 실계좌를 섞지 않으며 주문·OpenAI 호출·수집 작업은 추가하지 않는다. dev 기준 독립 기능 브랜치이며 PR #19·#20은 별도 작업이다.

## 카테고리와 평가

보유종목 조회 후 여러 종목을 선택해 직접 입력한 카테고리로 묶는다. 종목당 한 카테고리이며 기존 분류를 변경하거나 미분류로 이동할 수 있다. 빈 카테고리 객체 생성·다중 태그·공식 산업 자동 분류 기능은 아니다. 기존 카테고리 저장 내용을 그대로 사용하며 새 설정도 계정별 기존 paper DB의 settings에 저장한다. 거래 기록·모의 잔고는 변경하지 않는다.

카테고리와 전체 자산의 매입 원금(수량×평균 매입가), 현재 평가금액(수량×마지막 조회 단가), 총 미실현 평가손익, 수익률을 표시한다. 원화 환산·달러 환산·거래통화별 보기를 제공한다. 카테고리 필터로 합계와 종목을 좁힐 수 있고 종목의 현재 단가는 원래 거래통화로 별도 표시한다.

Decimal로 계산하며 화면에서만 통화 표시 자릿수로 반올림한다. 현금·매도 실현손익·수수료·세금은 포함하지 않는다. 같은 현재 참고 환율로 원금과 평가금액을 환산하므로 매입 당시 환율에 따른 실제 원화 손익이나 환차손익 분해 결과는 아니다. 평균 매입가·수량·가격·환율이 없거나 잘못되면 해당 합계를 0으로 채우지 않고 확인 필요로 표시한다. 서로 다른 통화를 환율 없이 합산하지 않는다. 토스 보유종목과 환율의 실제 운영 응답 호환성은 추가 검증 대상이다.

분류는 재로그인·서버 재시작 후 유지된다. 실제 보유 데이터는 기존 broker 메모리 캐시이므로 서버 재시작 후 다시 조회해야 한다. 실제 영속성은 기존 운영 DB 구성에 달려 있다.

## 종목별 예상 배당 자동 조회

종목을 선택하거나 코드를 입력하면 서버가 Finnhub의 종목 정보와 Basic Financials를 조회한다. `dividendYieldIndicatedAnnual`(제공처 예상 연환산 배당률)만 사용한다. TTM·과거 실적 배당률·과거 주당 배당을 미래 예상치로 대체하지 않는다. 해당 필드가 없으면 자료 없음이고 제공처가 명시적으로 0을 반환한 경우와 구분한다. 최신 배당 공시나 애널리스트 합의 예상치 전체를 독립 검증한 결과는 아니다.

배당률과 참고 주당 가격은 읽기 전용이다. 계산·저장 API의 사용자 입력 모델에 배당률·주가 필드를 없애 임의의 값 전송도 거부한다. 서버가 조회한 자료로 다시 계산하며 종목·통화를 검증한다. 종목 데이터의 통화로 투자금액을 입력하고 원화·달러 환산 결과를 표시한다. 주가를 조회하지 못하면 투자금 전액에 배당률을 적용하고 매수 수량 미계산임을 표시한다. 주가가 있으면 정수 매수 가능 수량·잔액을 계산하며 소수점 매수는 전액 투자 가정이다.

출처·제공처 지표명·조회 시각·가격 시각을 함께 표시한다. 제공처 데이터의 실제 산정 기준일은 응답에서 확인되지 않으므로 조회 시각을 산정 기준일로 설명하지 않는다. 예상 연 배당률이 유지되고 1년 보유한다는 시뮬레이션이며 배당은 감액·중단될 수 있다. 월평균은 연간 금액÷12로 실제 월 지급액이 아니고, 1회당 금액은 사용자가 지정한 횟수로 균등 지급하는 가정이다. 세율 기본 0%는 세전 가정이며 세법·원천징수·계좌 유형·조세협약은 자동 적용하지 않는다.

계산 조건과 조회 자료를 저장하되 시장 자료는 1시간까지만 재사용한다. 오래된 자료는 다시 조회해야 하며 페이지 열기만으로 외부 제공처를 호출하지 않는다. 기존 직접 입력 배당률로 저장한 구형 조건을 시장 데이터처럼 재사용하지 않고 새 종목 조회를 안내한다. 종목 조회·계산·저장 요청에서만 외부 조회가 가능하다. 성공 자료는 최대128종목·30분 메모리 캐시, 실패 재조회는 60초 제한, 분당 최대10개 새 종목 조회로 제한한다. 응답은 요청당1MB, 총 조회 시간25초로 제한하고 API 키는 헤더로만 전달한다. 오류 응답·키는 사용자 화면에 출력하지 않는다.

### 운영 설정 (이 작업에서는 적용하지 않음)

- `FINNHUB_API_KEY`: 운영자가 발급한 제공처 키. OpenAI 키가 아니며 새 유료 계정을 생성하지 않는다. 요금제·지원 시장·사용 권한은 별도 확인한다.
- `INVESTPILOT_DIVIDEND_SYMBOL_MAP`: 선택적인 JSON 종목 코드 매핑. 국내 6자리 코드는 제공처 지원 시장과 종목 코드를 검증한 후 매핑해야 한다. 거래소 접미사를 임의로 추측하지 않는다. 해외 티커도 제공처가 반환한 종목 코드와 통화를 대조한다.
- 키 미설정·권한 제한·예상치 미지원·국내 코드 미연결은 명확한 미제공 상태로 표시한다. 기본 배당률을 만들어 채우거나 사용자 직접 입력으로 전환하지 않는다.

공식 API 계약 참고: https://finnhub.io/docs/api 및 https://github.com/Finnhub-Stock-API/finnhub-go/blob/master/api/openapi.yaml 의 `/stock/profile2`, `/stock/metric`, `/quote`. Basic Financials는 가변 metric 객체이므로 필드 존재·형식 검증이 필수다. 실제 키와 국내·해외 종목별 예상치 제공 여부는 운영에서 추가 확인해야 한다. 검증은 합성 제공처 응답만 사용한다.

## 상단 환율과 그래프

기존 토스의 USD/KRW 참고 환율 경로만 사용한다. 보유종목 조회 또는 명시적 환율 갱신 시 유효한 환율을 확인한다. 단순 페이지 열기·10초 화면 갱신·그래프 열기는 저장된 기록만 읽으며 새로운 외부 환율 요청을 발생시키지 않는다.

상단에는 마지막 조회 환율·시각·유효기한 경과 여부를 표시한다. 클릭하면 최근 7일·30일·전체 기록을 필터링하는 그래프를 연다. 성공한 실제 조회 시각의 관측값만 최대 300개 계정별로 보관하며 거래소 전체의 과거 환율·실시간 연속 환율을 제공한다고 설명하지 않는다. 기록이 하나면 점 하나를 표시한다. 과거 수치를 임의 생성·보간해서 저장하지 않는다. 저장된 환율이 만료되면 합산에 재사용하지 않는다.

## 인증·검증·출시

기존 쿠키 인증·동일 출처 검사를 적용하며 계정은 요청 본문이 아닌 인증 컨텍스트에서 결정한다. 종목 분류의 일괄 변경은 트랜잭션으로 처리해 동시 저장 손실을 방지한다. 카테고리 문자열과 종목명은 textContent로 표시한다. 사용자별 토스 broker를 재사용하며 새 인증정보는 요구하지 않는다.

새 API: PUT /api/broker/categories/batch, GET/POST /api/broker/exchange-rate[/refresh], GET /api/broker/dividends/quote/{symbol}, POST /api/broker/dividends/calculate, GET/PUT /api/broker/dividends/scenario. 기존 GET /api/broker/breakdown과 종목별 분류 API는 유지한다.

모의 보유 데이터·환율로 합계 계산·누락 처리·계정 격리·재시작 보존·동시 분류 저장·배당 가정 및 임시 PostgreSQL을 검증한다. 브라우저 검증은 실제 로그인·실제 저장 API와 합성 broker만 사용하며 데스크톱/모바일 분류 변경·주입 방지·환율 모달·배당 저장/다시 읽기를 확인한다. 실제 거래·운영 DB 테스트·실제 배당 예측·배포는 수행하지 않는다. dev 병합과 Render 자동 배포는 별도 사용자 승인 대상이다.
