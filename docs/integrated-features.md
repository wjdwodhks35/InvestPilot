이 브랜치는 `dev`의 `b88b9b4f1f6fa42f6446db8346f167e3067d894c`를 기준으로 다음 개발 결과를 함께 통합합니다.

- PR #19: 기존 웹 서버에 읽기 전용 MCP 연결 (`ebb0b69862f9a467bc41387af7fbd3e7b6db6dcb`)
- PR #20: 공개 일봉·RSS 정기 수집 및 선택적 Drive 보관 (`1977fe47451197a796628fae3d499a24ea8939c2`)
- PR #21: 계정별 카테고리·원화/달러 평가, 종목 배당 지표 자동 조회, 환율 관측 그래프 (`98cbbd301f5190d78063e274c3370fe42be5b9c0`)

## 실행과 인증

기존 `pip install -r requirements.txt`, `python -m scripts.deploy` 시작 경로를 사용합니다. 별도 MCP 서버 프로세스는 필요하지 않습니다. MCP 전송 계층과 웹 서버의 lifespan을 함께 열고 닫으며 웹 시작 실패 시에도 MCP를 정리합니다. 수집을 활성화한 경우 기존 RSS 단독 루프 대신 수집 루프 한 개만 실행합니다.

MCP 디스패치 미들웨어는 마지막에 등록하여 웹 쿠키 인증과 계정 연구 미들웨어보다 먼저 처리합니다. MCP 요청은 연결된 계정의 기존 broker를 읽기 전용으로 사용합니다. MCP 토큰은 카테고리·배당·환율·수집 상태를 포함한 웹 API 로그인 권한으로 사용할 수 없습니다. MCP 요청이 배당 조회나 별도 계정 연구 작업·수집 작업을 시작하지 않도록 통합 테스트에서 확인합니다. 관리자가 별도로 활성화한 수집 루프는 서버 시작 시 실행됩니다.

## 운영 활성화 전 확인

개발 코드의 통합과 실제 운영 연결은 별개입니다. 이 변경은 병합·배포·키 변경·운영 DB 접근을 수행하지 않습니다. 기존 PR 세 개와 이 통합 PR은 같은 변경을 포함하므로 병합 순서를 별도로 검토해야 합니다.

1. 기존 운영 DB의 위치와 영속성, 기존 암호화 키 유지 여부를 확인합니다. 테스트 DB를 운영 DB로 사용하지 않습니다.
2. [MCP 안내](openai-readonly-mcp.md)에 따라 OAuth 제공처와 허용 클라이언트, 공개 HTTPS 주소를 확인하고 `python -m scripts.check_mcp`로 설정을 점검합니다. 오프라인 점검 성공은 실제 OAuth·ChatGPT 연결 성공을 의미하지 않습니다.
3. [자동 수집 안내](automatic-collection.md)에 따라 수집 대상·간격·영속 DB를 확인합니다. 수집·Drive 보관은 기본 비활성입니다. Drive 권한과 저장 한도를 확인한 뒤 승인된 환경에서 활성화합니다. 서버 휴면 중에는 수집하지 않습니다.
4. [포트폴리오 안내](portfolio-categories.md)에 따라 배당 제공처 키와 이용 권한을 확인합니다. 국내 종목은 검증된 제공처 종목 코드 매핑이 필요합니다. 데이터가 없으면 수익률을 임의로 채우지 않습니다. API 키가 없는 개발 환경의 모의 응답 검증은 실제 종목 지원을 보장하지 않습니다.
5. 사용자 승인 후 배포하고 실제 계정의 격리·OAuth 연결·포트폴리오 조회·설정 저장과 재시작 후 유지·배당 데이터 출처·환율 표시를 확인합니다. 실거래는 수행하지 않습니다.

환율 그래프는 성공한 조회 시점의 기록입니다. 배당 추정은 제공처의 예상 연환산 지표를 사용하며 확정 지급액·지급 일정은 아닙니다. 세금·수수료와 매입 당시 환율을 반영한 실현 손익은 별도입니다.
